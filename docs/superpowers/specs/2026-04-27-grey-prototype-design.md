# Grave Harvest Grey Prototype Design

## Цель

Собрать первый играбельный браузерный срез Grave Harvest на Phaser + TypeScript + Vite: игрок двигается по открытой арене, враги идут к нему, Bone Knives стреляют автоматически, враги умирают, дропают XP, level-up предлагает 3 апгрейда, смерть открывает экран результата.

## Границы среза

Входит:
- Milestone 0-4 из PRD.
- Один экран меню, один игровой экран, game over/retry.
- Серые/простые примитивы вместо финального арта.
- Тестируемая чистая логика для XP, апгрейдов, спавна и подсчета retention.

Не входит:
- Полные 10 минут баланса.
- Все 4 оружия, все 5 врагов, босс, мета-прогрессия и звук.
- Финальный visual juice.
- Мобильное управление.

## Архитектура

Проект делится на две зоны. `src/game` содержит Phaser-сцены и отрисовку. `src/domain` содержит чистую игровую логику и data-driven определения, которые можно тестировать без canvas.

Первый срез использует одну `RunScene`. Она отвечает за игровой цикл, ввод, простые physics-объекты, HUD и overlay level-up/game-over. Сложные системы пока не выносятся в полноценный engine, но данные врагов, оружия и апгрейдов уже лежат отдельно, чтобы следующий MVP-контент добавлялся без переписывания сцены.

## Компоненты

- `src/main.ts`: запуск Phaser.
- `src/game/RunScene.ts`: gameplay scene, input, camera, entities, HUD, state transitions.
- `src/domain/progression.ts`: формула XP, retention костей, расчеты уровня.
- `src/domain/upgrades.ts`: список начальных апгрейдов, фильтрация и применение.
- `src/domain/spawnDirector.ts`: бюджетный выбор врагов по времени.
- `src/data/enemies.ts`: Skeleton и базовые параметры для дальнейшего расширения.
- `src/data/weapons.ts`: Bone Knives.
- `src/styles.css`: базовая страница и canvas layout.

## Игровой поток

1. Игрок открывает страницу и видит меню.
2. `Start Night` запускает забег.
3. Игрок двигается WASD/стрелками внутри арены 2200x2200.
4. Skeleton спавнятся вокруг игрока и идут по прямой к нему.
5. Bone Knives каждые 0.8 сек летят в ближайшего врага.
6. При смерти враг оставляет XP orb.
7. XP притягивается в радиусе подбора.
8. При level-up игра ставится на паузу и показывает 3 карты.
9. Выбор карты усиливает игрока и возвращает игру.
10. При HP <= 0 показывается Game Over с временем, убийствами и уровнем.

## Ошибки и ограничения

Если доступных апгрейдов меньше трех, показываем доступные. Если апгрейдов нет, используем fallback `Grave Strength`. Если Phaser asset не найден, прототип не зависит от внешних asset-файлов и продолжает работать на generated textures.

## Проверка

Автотесты покрывают:
- `xpRequired(level)`.
- retention по времени и победе.
- фильтрацию апгрейдов без повторов и max stacks.
- применение базовых апгрейдов.
- spawn director: allowed enemies and budget scaling.

Ручная проверка:
- `npm run dev`.
- Открыть локальный URL.
- Начать забег, подвигаться, дождаться врагов, убить врага ножом, собрать XP, получить level-up, выбрать апгрейд, умереть, нажать retry.
